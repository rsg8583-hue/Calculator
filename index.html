Calculator

A small four-function calculator, originally written in Python with the Kivy UI framework. This page is a browser version of the same layout, so you can try it without installing anything.

Features

  • Addition, subtraction, multiplication and division
  • Decimal numbers
  • A Clear button to reset the display

Run the Python version

pip install kivy
python Calculator.py

Source code on GitHub.

You can also type on your keyboard.
